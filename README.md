## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы. Инструкция доступна [по этой ссылке](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/FuseBoatwright/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно пропустить.

4. Распакуйте архив в каталог, путь к которому не содержит кириллических символов и специальных знаков.

5. Запустите нужный скрипт.
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для запуска стратегии вместе с системой выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает выбранную стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** включает или отключает обход для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** меняет режим обработки сервисов из `ipset-all.txt`.  
  Это помогает при проверке ресурса, который без zapret работает, а с ним сталкивается с проблемами.  
  В скобках указано состояние:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - адрес проверяется на наличие в списке
    - `any` - фильтруется любой IP-адрес  
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет текущий фейк на другой из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие новой версии.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце процедуры доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может вернуть работоспособность приложения, если оно неожиданно перестало открываться.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` анализирует DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным BAT-файлом, а не через service, в панели задач должен появиться процесс winws.exe, выполняющий обход.  
Если этого не произошло, обратитесь к [#522](https://github.com/FuseBoatwright/zapret-discord-youtube/issues/522).

### Рабочей стратегии нет
- Откройте командную строку с правами администратора.
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Через текстовый редактор, запущенный от имени администратора, откройте файл `hosts` в созданной папке.
  - Вставьте скопированное содержимое в конец файла `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно были сохранены.

#### Гарантировать работу невозможно. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FuseBoatwright/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии могут устаревать и прекращать работать.**
> Стратегия способна работать некоторое время, а затем перестать обходить блокировку после обнаружения метода.
> В этом репозитории собрано несколько вариантов. Если готовые решения не подходят, создайте собственную стратегию на основе одной из них, изменив параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте сообщения об ошибках.

- Проверьте, присутствует ли адрес ресурса в списках доменов или IP-адресов.

- Испытайте другие варианты, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/FuseBoatwright/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?
- Сохраните ресурсы и данные, добавленные вами вручную.
- Перезапустите компьютер.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце ответьте Y.
- Удалите каталог zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/FuseBoatwright/zapret-discord-youtube/releases), файл вида `zapret-discord-youtube-...`.
- Нажмите правой кнопкой по архиву, откройте свойства и при наличии флажка разблокировки включите его, затем нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- По очереди проверьте разные скрипты `general`. Если нужные ресурсы недоступны, закройте программу через значок замка в панели задач и запустите следующую стратегию.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` убедитесь, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё находится среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- Дополнительные сведения есть в [#251](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions/251).

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить её.
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord.
- Проверьте работу приложения после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если браузерная версия также недоступна, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/FuseBoatwright/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если результата нет, дополнительно включите режим `ipset any`.

Учтите, что `ipset any` способен нарушить открытие множества сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема останется, создайте обсуждение в разделе [Discussions](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Решения для моей проблемы нет

- Опишите проблему [в разделе issues](https://github.com/FuseBoatwright/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Списки для обхода можно расширять самостоятельно:
- домены добавляйте в **`list-general-user.txt`**; поддомены учитываются автоматически;
- домены, которые нужно исключить, указывайте в **`list-exclude-user.txt`**. Это пригодится, например, когда IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не требуется;
- IP-адреса и подсети добавляйте в **`ipset-all.txt`**;
- исключения для IP-адресов и подсетей записывайте в **`ipset-exclude-user.txt`**;
  - файлы **`*-user.txt`** автоматически создаются при первом запуске `zapret` или `service.bat`.
